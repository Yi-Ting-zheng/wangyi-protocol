# MA-000 — Human Delivery Gate

> **Protocol:** Wangyi Protocol v1.0-draft　**Type:** BLOCKING delivery gate
> **Truth level:** `DEFINITION` (rule text); gate effects are `EMPIRICAL`.

## 1. Purpose

MA-000 governs the pipeline by which a machine-produced formal artifact
becomes deliverable to a human audience. It encodes the core dictum of the
human-machine contract:

> Machine-produced machine-knowledge; only knowledge that has passed axiom
> audit, gap registration, truth-grading, and full failure-sample retention
> is deliverable knowledge for human civilization.

## 2. Four-stage pipeline

```
① Machine artifact layer      — Lean files, build logs, verdict JSON
        ↓
② Readable summary layer      — per-declaration human-readable mathematical
                                summaries (a successful build is NOT a summary)
        ↓
③ Knowledge sedimentation     — GAP ledger entries, truth grades, defect
                                history appended to the project ledger
        ↓
④ Delivery gate (MA-000)      — all three prior stages complete + hash-locked
```

## 3. Normative rules

1. **Build ≠ archived.** A successful `lake build` completes stage ① only.
   Delivery requires stages ①–③.
2. **Summary completeness.** Each main declaration MUST have a summary
   stating: what is claimed, which hypotheses it rests on, which native
   objects it binds, and which gaps remain. Missing summary → BLOCK back to
   stage ②.
3. **Delivery status ≠ truth grade.** Delivery status
   (`MACHINE_VERIFIED` → `HUMAN_ARTICULATED` → `FULLY_ARCHIVED`) is an
   engineering-completeness axis; truth grade (§2 of spec) is a mathematical-
   credibility axis. The two MUST NOT be conflated in any report.
4. **Failure-sample retention.** Failed controls, blocked artifacts, and
   fixed false-PASS incidents MUST be retained per R05/R12.

## 4. Machine-readable summary format (recommended)

```yaml
declaration: <fully-qualified name>
claims: <one-sentence statement>
hypotheses: [<registered HYPOTHESIS names, or "none">]
native_bindings: [<core objects bound, with providing library module>]
gaps: [<GAP ledger ids, or "none">]
summary_sha256: <hash of the summary text>
```
